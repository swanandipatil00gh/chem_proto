EcoWash - Natural Organic Detergent Project
IMAGE ASSETS DIRECTORY
================================================================================

HOW TO ADD YOUR ACTUAL PROJECT PHOTOS:

1. Copy your project photos into this folder:
   EcoClean Website/assets/images/

2. For seamless plug-and-play integration with zero code changes, rename your photos
   to match any of the following standard filenames:

   - soapnuts.jpg          (Photo of Reetha deshelling or berries)
   - citrus-peels.jpg      (Photo of orange / lemon peel preparation)
   - wood-ash.jpg          (Photo of wood ash sieving / lye water settling)
   - neem-leaves.jpg       (Photo of fresh neem leaves / bio-preservative decoction)
   - decoction-setup.jpg   (Photo of boiling / heating / lab apparatus)
   - ph-testing.jpg        (Photo of pH strip or digital pH probe testing)
   - stain-testing.jpg     (Photo of fabric swatches / stain cleaning trial)
   - final-prototype.jpg   (Photo of finished EcoWash liquid in bottle/flask)

3. If your files have different filenames or formats (e.g., .png, .jpeg, .webp):
   Simply open index.html and update the 'src' attribute of the corresponding <img> tag.

4. Note on Fallbacks:
   If no .jpg is present, the website automatically displays clean, professional SVG
   scientific illustrations so the website never displays broken image icons.
